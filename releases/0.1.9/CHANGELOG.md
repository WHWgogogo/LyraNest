# LyraNest 0.1.9

发布日期：2026-07-25

## 升级注意事项

- Android 应用包名由 `com.harmonymusic.player` 更换为 `com.lyranest.player`。从 0.1.8 升级时，Android 会将 0.1.9 视为新应用；旧应用中的离线下载、登录状态和本地设置不会自动带入。
- Web 端本地状态键已统一为 `lyranest.*`；浏览器首次进入时会自动迁移旧的 Harmony 键值，避免收藏、歌单和登录状态丢失。
- Docker 可以将音乐目录以只读方式挂载。刮削结果、封面、歌词、队列和缓存均保存到数据/缓存目录，不会写回音乐库。

## 曲库扫描与服务端

- 重构曲库扫描为流式分阶段扫描：首次启动进行后台全量扫描，扫描过程不会阻塞健康检查或登录。
- 新增增量扫描：只处理新增、修改或删除的文件，避免每次重新扫描整个大曲库。
- 新增可持久化的“自动热更新”开关；开启后使用 `fsnotify` 监听音乐目录的创建、删除和修改事件。
- 通过库更新事件向已连接客户端推送曲库变动，Windows、Android、Web 和 fnOS 页面可及时刷新。
- 修复大曲库首次部署/启动可靠性：不再创建空音乐目录、不递归修改曲库 ACL，并在曲库路径无效时给出明确状态。
- 将本地标签读取与网络刮削拆分为独立持久化任务队列，支持失败退避、最大重试、恢复和显式重新入队。
- 新增统一服务端资源缓存，封面、歌词和相关网络资源复用缓存目录，减少重复下载。

## 刮削与元数据

- 新增 JSON 可配置刮削源：服务端动态加载、列出、删除来源，并支持响应路径映射、超时控制和运行时热加载。
- 内置核心来源保持 MusicBrainz 与 Cover Art Archive；网易云、QQ 音乐、酷狗等来源改为独立 JSON 导入文件，不再硬编码进服务端或客户端。
- 发布包新增 `scrape-sources` 目录，包含三方来源导入文件、组合来源文件和说明文档。
- 保留严格置信度阈值和可解释字段差异；候选结果展示来源、匹配度与变更字段。
- 新增独立刮削工作台：单曲搜索需手动点击后才执行，避免选错歌曲即自动搜索。
- 支持已刮削/未刮削分类；“已刮削”要求具备标题、艺术家、有效封面和歌词，元数据判断不再将色块占位图当作封面。
- 新增批量刮削、批次持久化、全选、分页、手动清除、转入单曲刮削、自动刮削规则与自定义置信度。
- 批量任务保存前两条严格候选；审核页采用“当前资料 / 候选 1 / 候选 2”三列对照，可为每首歌选择候选与字段后再应用。
- 修复 `album_artist` 缺失导致的候选应用失败；应用后即时刷新曲目、封面与歌词资源。
- 支持批量优先使用导入来源或启用全部来源；任务状态跨页面返回后保持，不再丢失进行中的检索进度。

## 下载、缓存与播放

- 将自动下载与自动缓存完全拆分：自动下载写入离线下载库，自动缓存写入独立播放缓存目录。
- 自动缓存改为网络流播放同时写入缓存，不再等整首下载完成才开始播放。
- 新增自动下载开关、自动缓存开关、缓存配额、下载空间配额和“一键清理缓存”。
- 离线下载列表、播放器和缓存控制器统一处理封面、歌词、音频及索引，离线登录后仍可浏览和播放已下载歌曲。
- 优化内外网地址切换、失败后单次回退、带路径前缀的 API/播放/封面/下载地址构造和播放转码请求。
- 修复网络从局域网切换到流量后仍错误优先访问内网地址的问题，并改善封面刷新速度。

## 客户端与 Web 界面

- 全端替换 Harmony 旧品牌标识、应用 ID、页面文案、存储键、图标和发布名称为 LyraNest；`HarmonyOS Sans` 字体名及第三方依赖保持不变。
- Web 新增完整刮削页面并统一为音乐管理页的卡片式视觉规范，修复中文乱码、未汉化标题、遮挡、对齐、间距、候选卡片和审核表格问题。
- 管理与曲库页面增加批量选择：全部曲目可批量收藏；下载页支持长按多选和批量删除；歌曲右侧收藏、刮削、下载操作统一收进“更多”。
- 修复专辑统计单位为“张”、艺术家统计单位为“位”。
- 修复浏览器缩放时侧边导航标题溢出，以及底部播放栏与导航栏轻微重叠。
- 修复发现页（猜你喜欢、每日三十首、排行榜、最近推荐）歌曲卡播放图标位置随标题长度变化的问题，图标现固定在每行右侧。
- fnOS Web UI 同步修复侧边栏响应式溢出与上述曲库统计显示问题。
- Windows/Android 设置页补充服务地址、扫描热更新、刮削任务、转码和缓存相关状态展示；系统媒体栏与桌面歌词同步适配新的应用包名。

## Docker、fnOS 与发行工程

- Docker 部署改为安全的只读曲库挂载模式；数据、缓存、刮削候选和任务状态全部落入独立持久化目录。
- 新增完整 Docker 离线镜像归档、Compose 配置与环境变量示例，镜像标签为 `lyranest-server:0.1.9`。
- fnOS FPK 服务端升级：内置网关、Web UI 基础路径和配置向导同步至 0.1.9。
- 客户端打包脚本修复 Windows `media_kit` MPV 归档被错误重新打包而触发完整性校验失败的问题。
- 统一 Windows x64、Android ARM64、fnOS x86、Docker AMD64 的发行版本号为 `0.1.9`，并提供 SHA-256 校验清单。

## 修复汇总

- 修复空曲库启动、热更新不刷新、自动缓存开关无效、先下载后播放、内外网切换失败、外网播放失败与封面更新慢的问题。
- 修复批量刮削候选无法选择、字段全选禁用、未达阈值卡片无法清除、后台状态丢失、来源选择不生效、封面不刷新和候选应用失败的问题。
- 修复刮削页面候选数量限制提示不一致、缺失全选入口、列表拥挤、卡片重叠、审核字段布局混乱及多处控件对齐问题。
- 修复 Web 与 fnOS 的响应式导航、底部播放器间距、专辑/艺术家单位和发现页播放按钮对齐问题。
