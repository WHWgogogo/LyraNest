LyraNest 0.2.6 更新日志

新增功能
- Windows 新增沉浸式标题栏，窗口外观与深色、浅色主题保持一致。
- Windows 新增系统托盘后台驻留，可在托盘中播放、暂停、切换歌曲，并开关或锁定桌面歌词。
- Android 新增通知栏标题与歌词互换开关，可按个人偏好调整锁屏和通知栏显示。
- 播放页和歌曲详情新增采样率显示，能看到 44.1 kHz、48 kHz、96 kHz 等音频信息。
- 曲库的列表、图标和详细模式现在都支持批量全选、收藏、下载和加入播放队列。
- TV端全新重构，支持有声书功能。
- 新增全新插件小爱音响桥接器，使用小爱音响语言播放你NAS中的音乐。详见https://github.com/WHWgogogo/LyraNest-Xiaomi-Bridge

播放与歌词
- 修复 Android 在局域网播放时启动慢、长时间缓冲的问题。
- 修复转码播放拖动进度后跳回开头、总时长不显示和听歌记录不准的问题。
- 修复部分 FLAC 歌曲在播放页显示“未知格式”的问题。
- 改进 Windows 桌面歌词的渐变效果，与播放页视觉保持一致。
- 修复 Android 桌面歌词“从左到右”填充不生效的问题。
- 修复歌词渐变、逐字填充在不同平台表现不一致的问题。
- 修复浅色主题下播放列表文字不清晰的问题。

下载与稳定性
- 显著提升 Android 自定义下载目录的下载速度，并减少下载时的界面卡顿。
- 优化大文件校验、断点续传和多任务下载的稳定性。
- 修复 Android 缓存配额自行变化、自定义滑块无法正常调整的问题。
- 登录状态改为长期保持，日常使用不再频繁要求重新登录。
- 修复局域网自动发现后连接到错误地址的问题，旧版服务端也可正常发现。

有声书与 Web
- 修复 Web 端有声书切换章节后倍速恢复为 1 倍的问题，刷新页面后也会保留倍速。
- 完善 Web 端有声书倍速、定时和底部播放控件的深色模式。
- 修复音乐模式下误显示有声书曲库的问题。

Windows 体验
- 修复最小化、最大化和关闭按钮无响应或位置跳动的问题。
- 修复 Windows 设置页及子页面缺少返回操作的问题。
- 改进托盘隐藏、再次启动唤醒和真正退出时的稳定性。

TV端
- 重构了TV端的UI布局
- 新增逐字动态歌词与双语对照歌词
- 新增TV端有声书播放
