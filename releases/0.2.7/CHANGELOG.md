LyraNest 0.2.7 更新日志

安装向导与飞牛生态
- 飞牛（fnOS）安装向导新增媒体目录挂载提醒（可选），引导新用户在飞牛「授权目录」步骤中挂载音乐与有声书文件夹，若暂未准备好可跳过并在后续设置中补充，彻底解决首次安装曲库为空的困惑。
- 飞牛（fnOS）安装向导新增自定义局域网端口设置（可选），支持配置独立访问端口供局域网免登录或移动端/桌面端客户端直连。
- 飞牛兼容版（Compat）FPK 同步支持安装向导目录挂载提示与自定义服务端口配置，优化目录与端口变更回调。

曲库管理与去重清理
- 新增一键曲库去重功能：支持基于「歌曲标题 + 艺术家」智能匹配重复音频文件。
- 提供 4 种智能保留策略：可根据「最高音频规格/码率」、「最长播放时间」、「最早添加时间」、「最新添加时间」自动筛选保留曲目，其余重复歌曲一键批量隐藏。
- 新增隐藏歌曲物理清理功能：管理员可在隐藏歌曲管理中批量物理删除重复或无效音频文件，操作前自动检测目录写入权限并提示。
- 优化收藏夹播放逻辑：点击播放收藏时仅将收藏曲目加入当前播放列表，不再误拉取全部曲库。
- 增强按目录浏览封面识别：当歌曲未内嵌封面且未刮削时，自动使用同目录内的封面图片作为歌曲展示封面。

有声书与书架
- 全新重构有声书书架卡片设计：视觉风格与音乐曲库保持一致，优化大图封面、播放进度条、演播者与章节展示。
- 优化书架顶部操作布局：将选择书库与入库扫描按钮右置，提升界面美观度与标题可读性。
- 优化有声书独占播放页：提升大屏与移动端不同视口下的全屏沉浸式播放体验。

Web 端与移动适配
- 支持标准 PWA（渐进式 Web 应用）封装：苹果 iOS 与鸿蒙 HarmonyOS 用户可直接「添加到桌面」，获得全屏无地址栏的原生应用级使用体验。
- Web 端通知栏与锁屏卡片升级：集成 MediaSession API，显示当前播放歌曲名、艺术家与高清封面，支持锁屏切歌与暂停播放。
- 重构兼容模式下的音乐报告与有声书报告：彻底解决小屏幕设备上的横向溢出与内容截断问题，采用自适应卡片排版。
- 修复移动端 Web 播放页触摸穿透问题：避免点击逐字歌词开关或颜色选择器时误触底层歌词滑动。

客户端与跨平台支持
- 修复了收藏页面播放歌曲错误的拉取整个曲库的问题。
- 修复了定时结束播放不生效的问题。
- 新增了对fnid的支持，现在可以直接在外网访问地址填写fnid实现外网访问。

TV端
- 优化了首页的表现。
- 新增了转码功能。
- 播放页新增了标签功能。

小爱桥接器
- 修复了口令拦截不生效问题。
- 新增了自定义语音口令功能。
- 新增了语音口令控制播放曲库、歌单功能。
