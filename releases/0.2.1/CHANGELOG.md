0.2.1 版本更新日志

- 在这个版本，有了独立的TV客户端，现在您可以在大屏上畅销你的音乐库了！
- 支持二维码扫码登录，无需手动输入地址和密码。
- 支持曲库切换。
- 播放队列支持完整列表播放。
- 优化遥控器焦点导航体验。
- 隐藏歌曲列表可查看和恢复。

多用户支持

- 新增多用户体系：支持管理员和普通成员两种角色。
- 管理员可创建、管理用户，按曲库分配访问权限。
- 账户上限 5 个，满足家庭使用需求。
- 每个用户独立的收藏、歌单、播放记录和隐藏歌曲列表。
- 用户可隐藏自己曲库中的歌曲（软删除），不影响其他用户。

扫码登录

- 支持二维码扫码登录：已登录设备生成二维码，新设备扫描即可完成授权。
- TV 客户端无需手动输入服务器地址和密码，开机即生成二维码。
- 手机、桌面端均可作为授权设备，也可作为被授权设备。

客户端新增功能

- 新增「按目录浏览」功能（默认关闭，可在设置中开启），按文件夹层级浏览音乐。
- 支持多账号快捷切换，无需退出重新登录。
- 新增浅色/深色主题切换，支持跟随系统。
- 新增账户设置页，统一管理服务器地址、账号信息。
- 新增局域网服务端发现功能，自动扫描局域网内的 LyraNest 服务。
- 歌曲列表支持长按多选、全选、批量加入歌单。
- 新增自定义歌单封面功能（网页端与客户端均可上传）。
- 曲库图标视图支持调节图标大小。
- 查看已隐藏歌曲，支持逐首恢复或一键全部恢复。

网页端

- 新增独立设置页面，刮削、音乐管理、关于整合至设置中。
- 导航栏精简为：发现、曲目、报告、按目录浏览。
- 支持浅色/深色主题切换。
- 新增按目录浏览功能。
- 新增多用户管理页面。
- 新增隐藏歌曲管理。
- 新增自定义歌单封面上传。
- 优化设置页面布局，统一卡片风格。

刮削优化

- 批量刮削的置信度设置改为滑动条，与自动刮削一致。
- 新增批量刮削自动应用开关，候选达到阈值后可直接应用。
- 新增逐字歌词开关，按需获取逐字歌词。
- 刮削评分优化：有封面的候选优先排在前面。
- 修复批量应用时部分歌曲报错的问题。
- 提升刮削和应用阶段的稳定性。

服务端与部署

- Docker Compose 配置简化，挂载多个音乐目录只需在 volumes 中添加一行。
- 服务端自动发现 /music、/music1、/music2... 等挂载目录。
- 修复扫描写入失败时可能导致的阻塞问题。
- 修复批量应用阶段封面重复下载的问题。
- 提升大曲库下的整体性能。
- 飞牛 FPK 挂载新目录后自动重启，无需手动操作。

其他改进

- 网页端默认音量调整为 100%。
- 修复浅色模式下多处 UI 未适配的问题。
- 修复设置页面卡片宽度不一致导致的抖动。
- 修复 TV 客户端播放列表只播放单首的问题。
- 修复客户端切换账号后无法播放的问题。
- 移除安卓端误申请的短信权限。
- 修复按目录浏览中深层目录歌曲不显示的问题。
- 修复批量刮削进度条关闭后刷新又重新出现的问题。
