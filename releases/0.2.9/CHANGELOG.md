LyraNest 0.2.9 更新日志

播放界面全面重做

- 播放页新增「负一屏」：在播放页往右滑即可滑出，装这首歌的来路（专辑、艺术家、格式、大小）与歌曲推荐；桌面端与横屏可在右栏直接选「负一屏」，同一份内容、同一份设置。
- 负一屏分区可自由开关：专辑信息、艺术家信息、歌曲推荐三块，按自己的习惯勾选，至少留一块。
- 推荐列表下面新增「同专辑 / 同艺术家」：整张专辑连着听是最自然的下一步，优先同专辑，专辑字段为空时退回同艺术家，最多 8 首。
- 播放页主屏的歌词位可以换成「律动柱」。
- 新增整首歌频谱图：横轴时间、纵轴频率，一眼看出这首歌的高频是到 20kHz 还是被截在 16kHz，用来判断手上的「无损」是不是真的无损。Web 端在曲库「更多」菜单里也能看。

播放页布局与主题

- 新增四种播放界面容器样式：毛玻璃卡片、无界悬浮、复古黑胶卡片、极简。
- 新增六套主题色系，设置里可自由切换；主题构建改用色系种子色，整套配色一起变。
- 平板与 Windows 的侧栏改成悬浮圆角卡片。
- 手机端新增下滑关闭播放页的手势：在播放页往下拖即可退回曲库，不用再去点左上角返回。
- 主页面切页改成跟手拖动 + 两页同场交叉位移，配高斯模糊过渡；切页后键盘不再自己弹出来。

音频与播放品质

- 播放品质面板新增 PCM / WAV 档位可通过点击播放标签快速切换。
- 修掉转码与源码来回切换后停止播放、或界面显示已停但仍在后台转码的问题。
- 修复开启缓存时外网转码情况下依旧在后台满速拖无损原盘的问题。
- Android 网络流开启磁盘缓存，弱网下拖动进度条更稳。
- 播放进度上报裁剪队列窗口。
- 修掉一首歌播完卡在暂停、不进下一首；修掉切歌后播放图标莫名变成暂停、要点三次才能恢复。

曲库与收藏

- 全部曲目、收藏、歌单、已下载、本机分区都补齐「播放全部 / 随机播放」两个入口。
- 随机播放改为即时真随机：回退上一首之后再点下一首，不会固定重放刚才那一首。
- Web 端曲库点一下整行即可播放，不用再精确点到封面。
- 曲库支持多选 / 全选批量操作，单曲可查看技术信息与一键复制路径。
- 歌单支持重命名。
- 最近入库歌曲展示上限从 20 首提升到 50 首。

本机音乐

- 新增本机音乐扫描：可扫描整机或指定目录（Android 支持 SAF 目录选择），自定义短音频过滤规则，扫到的歌可就地播放或上传到 NAS。
- 扫描统一路径规范化，并按路径与指纹双重去重，同一首歌不会因为大小写或符号链接重复入库。
- 白名单叠加私有加密后缀黑名单，拦截 QQ 音乐等专有格式；0 时长与未知时长的提示音不再入库。
- 新增「隐藏歌曲」管理页：集中查看被去重或手动隐藏的全部曲目，支持单曲恢复与批量移出。

歌词

- 新增插件-LrcApi，支持逐字歌词识别与纯音乐占位识别。
- 启用LrcApi插件后支持在播放时自动搜索在线歌词，命中后按偏好写入服务端或只保存在本机。
- Windows 任务栏新增逐字歌词显示，macOS 新增菜单栏逐字歌词，跟随播放进度高亮，可在设置里开关。
- 修复桌面端播放页悬停歌词闪烁问题。

有声书

- 听书播放器新增专属书类标签与章节树，支持整本书籍加入跨端投送队列。
- 支持自定义跳过片头片尾区间，设置能存住也能关掉；跳片头与拖动进度改用原生 Range 定位，不再强制转码。
- 听书进度上报改用落盘队列，与音乐端一致，断网也不丢；修复听书报告恒为 0 的问题。
- 书架与作品卡片支持就地重命名。
- 插件中心新增第三方有声书搜索与下载面板，可一键搜索全网资源并直接下载导入私有书架。
- 下载章节补齐缺省 id 与标题，失败原因显示在弹层内而不是被遮住。


连接与登录

- 全端零配置扫码登录：手机扫描 Web 端或 TV 端二维码即可完成配对与跨端鉴权，不用再手动输入 IP、端口和密码。
- 局域网地址切换时自动探活并快速回退到外网地址，取流失败先故障转移再重试。
- 修掉同一 IP 不同端口多实例部署时的 Session 串扰。

TV 端

- 界面缩放改为按屏幕高度自适应，小屏上不再出现「UI 巨大」；新增缩放档位与渲染分辨率开关。
- 听歌时的 GPU / CPU 占用大幅下降：模糊层不再每帧重算、光斑降到 2fps、逐字歌词高亮不再跟 vsync 跑、背景光斑与进度条各自独立重绘边界。
- 修掉「一进音乐就闪回桌面」——启动与退出不再切换输出分辨率。
- 遥控器方向键语义修正：快进不弹卡片，卡片唤起后左右键回到图标定位；根路由按返回弹出退出确认。
- 侧边歌词在末尾几行不再来回跳。

服务端

- 新增整首歌频谱图接口与律动频谱数据接口（服务端 PCM 解码 + FFT），结果落盘缓存，二次请求直接读盘。
- 频谱图纵轴改为对数刻度（之前一直是线性，刻度对不上），律动分析采样率与频段划分重新校准。
- 转码新增 PCM / WAV 输出。
- 服务端运行日志同时落盘，并在 GUI 与开始菜单提供查看入口。
- 新增本地曲目智能刮削候选查询与上传元数据落库；刮削算法升级 V2，引入证据门控与冲突抑制，大幅降低同名歌曲、多艺人混淆导致的误刮削。
- 挂载目录失效时自动标记状态，允许在管理面板里安全解挂与删除，避免后台配置报错锁定。
- 识别并清理 NAS 曲库中的私有加密音频。
- 修掉自定义源刮削的性能问题与 Watcher 重复扫描风暴。
- 新增定向曲库查重与隐藏，以及自定义存储目录配置。

Web 端

- 播放页可点击封面查看频谱图，判断是否无损。
- 修掉收藏区只显示当前分页里的歌、其余收藏全部不可见的严重问题。
- 修掉矮窗口下播放页底部露出黑条、插件配置弹窗底部按钮被播放栏遮住。
- 曲库列表、歌单、有声书下载等处的交互细节一并修整。
