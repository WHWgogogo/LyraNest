# LyraNest 0.2.0

发布日期：2026-07-31

## 0.2.0 版本更新日志

### 播放与跨端续播

- 修复多服务端、同账号环境中播放请求取错服务端地址导致的流媒体打开失败。
- 媒体流和封面访问改为会话绑定的短期令牌，提高鉴权安全性与多服务端兼容性。
- 新增跨端续播功能：保存当前歌曲、播放队列、队列索引和停止位置，同步三端播放进度。

### Android 与桌面客户端

- 重构 Android 后台播放、返回确认、前台媒体服务和系统媒体会话流程。
- 修复后台播放时状态栏进度丢失、返回后播放器状态不同步、再次进入后声音重叠等问题。
- 通知栏增加播放进度和系统媒体控制同步。
- “更多”菜单新增“编辑信息”功能。
- 优化了设置中的各项设置布局。
- 优化了播放页的布局。

### 服务器端

- 增加服务器切换、退出当前账号和服务端配置管理入口。
- 每台服务器保存独立的地址配置、登录状态、账号会话和当前选择状态。
- 修复多台服务器使用相同账号密码时，媒体令牌、缓存来源或当前地址互相污染的问题。

### 歌词

- 播放页、展开歌词和桌面歌词统一支持双语歌词功能。
- 支持 A2 Enhanced LRC、YRC 逐字歌词。
- 新增应用内与桌面逐字歌词高亮、双语歌词配对、逐字颜色和歌词底色设置。
- 优化长英文歌词换行、译文显示和高亮对齐。
- 增加播放页长单行歌词使用平滑横向滚动功能。
- 增加实验性功能，对于没有逐字歌词的歌词使用算法模拟实现逐字歌词效果。

### 刮削与曲库管理

- 批量刮削支持候选审核、字段选择、候选编辑、应用进度和当前处理歌曲提示。
- 封面下载失败时保留其它可应用字段并记录重试状态。
- 修复 0.2.0 服务端刮削后封面无法加载等访问链路问题。
- 刮削时增加了刮削进度的展示功能。

### 服务端性能

- 修复批量刮削时，内存占用较高的问题。
- 提升了刮削时文件的写入效率。
