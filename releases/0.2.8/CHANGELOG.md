LyraNest 0.2.8 更新日志

投播生态与多设备音频输出
- 新增全新 AirPlay 2 桥接支持（LyraNest AirPlay Bridge），支持将曲库音频无线投送至苹果 HomePod、Apple TV 及第三方 AirPlay 兼容音箱，支持全端独立音量与播控调节。
- 新增全新本机音频直出支持（LyraNest Local Output），专为 NAS 与主机硬件设计，通过 ALSA / MPD 直通 NAS 本地 3.5mm 耳机孔或 USB DAC 外置声卡，无损原音输出，内存占用仅 13MB。
- 优化全端「投送中心」：统一聚合 AirPlay 2、本地声卡、DLNA 及小爱音箱四大通道，支持设备状态实时探测、外接播放器进度条拖拽同步（Seek Offset）与音量滑块调节。
- 小爱音箱桥接器全面升级至 v1.1.6：新增多音箱会话隔离与多账号用户设备绑定，支持有声书语音点播与双向断点续播，引入虚拟播放时钟解决休眠状态回传延迟与断流问题。

连接架构与免配扫码登录
- 全端引入零配置 X25519 局域网端到端加密扫码登录：手机 App 扫描 Web 端或 TV 端二维码即可秒级完成安全配对与跨端鉴权，彻底告别手动输入 IP、端口与密码。
- 飞牛（fnOS）连接生态增强：重构 FNID 多端点竞速优选与双签名鉴权算法，大幅提升无公网 IP 环境下的跨网穿透连通率与冷启动速度。
- 会话与实例隔离加固：修复同一 IP 不同端口多实例部署时的 Session 串扰问题，保障多媒体服务独立运行。

无损格式与网络串流扩展
- 原生支持 STRM 网络流媒体文件：音乐与有声书全面支持 .strm 文件识别与入库，支持 HTTP/HTTPS 远程流的 302 重定向、反向代理与按需动态转码。
- 原生支持 CUE 虚拟分轨与切片串流：整轨音频（FLAC/APE/WAV）配合同名 .cue 索引文件即可自动虚拟分轨入库，服务端支持任意时间偏移切片 Seeking，实现精准秒开。
- 大幅扩充无损音频支持：新增 DSF、DFF（DSD 母带级音频）、WavPack、CAF 与 AIFF-C 高清无损音频解码嗅探与元数据提取，集成 APE 专用头部解析器。

曲库治理与智能刮削
- 新增独立「隐藏歌曲」管理页：支持集中查看被去重或手动隐藏的全部曲目，支持单曲恢复与批量一键移出隐藏名单；TV 端深度适配遥控器方向键快捷操作。
- 优化挂载目录失效容错：磁盘离线或物理路径变更时自动标记失效状态，并允许直接在管理面板中安全解挂与删除，避免后台配置报错锁定。
- 升级智能刮削算法 V2：引入证据门控与冲突抑制模型，大幅降低同名歌曲、多艺人混淆导致的误刮削；强化基于目录层级与 URL 的路径元数据推断机制（PathMeta）。

有声书深度优化
- 插件中心新增第三方有声书搜索与下载面板，支持一键搜索全网有声书资源并直接下载沉浸式导入专属私有书架。
- 有声书全屏播放器体验升级：新增专属书籍标签与章节树，支持整本书籍加入跨端投送队列，全面对齐倍速播放记忆与跨端断点续播。

UI 交互与全平台客户端
- 移动端新增悬浮毛玻璃胶囊导航栏（设置中可自由开关），搭配拟物化旋转黑胶 Disc 迷你播放器，单手滑动更顺手。
- 正式推出 macOS 桌面客户端（通用架构 DMG / ZIP）与 iOS 移动客户端（IPA），实现苹果生态无缝融入。
- Android TV 端全面进化：优化遥控器 D-Pad 焦点流动与大标题自适应字号排版，同步对齐 STRM 串流架构与 X25519 零配置扫码登录。
- 全 NAS 体系官方安装包全面覆盖：飞牛 fnOS（原生/兼容版 FPK）、群晖 Synology（SPK）、铁威马 TerraMaster（DEB）、威联通 QNAP（QPKG）、绿联 UGnas（UPK）、畅网 CWNAS（CPK）。
