0.2.3 版本更新日志(简化版)

音乐下载插件

- 新增插件市场:支持安装 Solara 与 SQMusic 音源下载插件,管理员配置后端地址后可为成员开启下载权限。
- 新增下载搜索:多音源搜索、音质选择、加入下载队列,支持进度查看、取消、重试与失败移除。
- 下载完成后自动入库并创建「XX 的下载」个人曲库,文件按 用户/歌手/专辑 归档。

歌单导入导出(新功能)

- 新增 GoMusic 与 TuneMySong 歌单导入插件,粘贴分享链接即可导入。
- 支持 JSON / M3U 歌单文件导入,歌单可导出为 M3U / JSON。

客户端

- 新增拼音字母轴:按歌名/歌手/专辑排序时可快速定位首字母,中文按拼音排序。
- 离线下载使用真实歌名与格式保存,内嵌封面、歌词与标签;修复无法修改存储路径的问题。
- 新增睡眠定时(15/20/30/45 分钟与自定义);歌词偏移改为紧凑底部条。
- 修复文件夹浏览无法返回上级目录、下载队列失败歌曲无法移除的问题。
- 修复播放进度同步后点击播放仍从头开始的问题。
- 修复 Android 桌面歌词逐字渲染卡顿。
- 优化大列表按需加载与播放条性能。
- 修复客户端按目录访问无法显示封面的问题，支持命名为cover的专辑图，如果没有则回退至路径中任意图片文件，依旧没有则回退至第一首歌的封面。
- 修复部分双语歌词无法正确显示的问题。
- 修复歌曲详细歌词切换歌曲时，歌词不切换的问题。


TV 客户端

- 新增退出确认,避免误触返回键直接退出。

飞牛 fnOS(FPK 专享)

- 支持飞牛统一网关登录:绑定后打开「域名 /app/lyranest」自动登录。
- 首次安装可用飞牛管理员账号创建 LyraNest 管理员,初始密码可找回。

服务端性能与稳定性

- 修复空闲时 CPU 占用异常问题。
- 优化大曲库权限检查与概览统计,避免 SQLite 读并发耗尽。
- 修复曲库删除因残留扫描记录失败的问题。
- 下载入库不再触发全库重扫,下载完成即自动入库存活。
